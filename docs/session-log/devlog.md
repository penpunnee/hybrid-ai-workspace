### เลือกวิธีแก้จากหลักฐาน ไม่ใช่จากความสวย

วัดบน **Python 3.11.15 ของ prod จริง** ก่อนเขียนโค้ด:
- `asyncio.wait([coro, coro])` → **`TypeError: Passing coroutines is forbidden`**

  `send_loop` **ไม่กลืน cancel** = ไม่มี log error ปลอม
  ⛔ นี่คือเหตุผลที่ **ไม่เลือก `session.close()`** ทั้งที่มันใช้ได้: `recv()` จะโยน `APIError`
  เข้า except นั้น ⇒ พิมพ์ ERROR **ทุกครั้งที่ปิดหน้าเว็บปกติ** = ไปปนกับสัญญาณ 1008/1011

- ⛔ ไม่เลือก timeout ครอบ `__anext__`: การรับประกัน "cancel `recv()` ปลอดภัย" ของ
  `websockets` เป็นระดับ `ws.recv()` **ไม่ครอบการ cancel `__anext__()` ของ async generator
  แล้ววนเรียกซ้ำ** ซึ่งมี state ของตัวเอง

- **failing test ที่ค้างแทนที่จะแดง = เครื่องมือวัดเสียเอง** ต้องครอบ timeout เสมอ

#### 🔒 XSS ที่ CodeRabbit จับได้ (ของจริง)
`renderMarkdown` escape แค่ `& < >` · `<`/`>` กัน "เปิดแท็กใหม่" ได้ แต่**ไม่กันการแตกออกจาก

ข้อความ `onerror=` ที่อยู่ *ข้างใน* ค่า attribute ที่ escape แล้วนั้นไม่มีพิษ regex แยกไม่ได้
