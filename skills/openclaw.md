# OpenClaw — AI Agent platform (open source)

แพลตฟอร์มตัวแทนปัญญาประดิษฐ์ (AI Agent) แบบ **open source** สำหรับสร้าง "ผู้ช่วยส่วนตัว"
ที่ไม่ได้มีหน้าที่แค่คุยหรือตอบคำถาม แต่ **"ลงมือทำงาน" แทนผู้ใช้ได้จริงบนเครื่อง
คอมพิวเตอร์ของผู้ใช้เอง**

พัฒนาโดยโปรแกรมเมอร์ชื่อ **Peter Steinberger**

## ต่างจาก AI Chatbot ทั่วไปยังไง

มีสภาพเป็น **Agent** ที่ตัดสินใจและทำตามคำสั่งแบบเป็นขั้นตอนได้ — เปรียบเหมือนการ
**"สร้างมือและเท้า" ให้ AI** เพื่อให้รับคำสั่งที่เป็นภาษามนุษย์ แล้วออกไปคลิก ค้นหา
หรือจัดการงานตาม workflow ให้อัตโนมัติ

| จุดเด่น | รายละเอียด |
|---|---|
| **สั่งงานผ่านแอปแชทที่ใช้ทุกวัน** | ไม่ต้องเปิดโปรแกรมหรือเว็บใหม่ — พิมพ์สั่งผ่าน Telegram, Discord, WhatsApp, Slack ที่ใช้อยู่แล้ว |
| **เข้าไปทำงานในเครื่องได้จริง** | รันบนเครื่องผู้ใช้ (laptop หรือ server ส่วนตัว) → จัดการไฟล์ ค้นหาข้อมูล ส่งอีเมล รันโค้ด บนเครื่องได้โดยตรง |
| **Self-hosted ปลอดภัย/เป็นส่วนตัวสูง** | ติดตั้งเอง ข้อมูลอยู่ใต้การควบคุมของผู้ใช้ 100% · เลือกได้ว่าจะต่อ "สมอง" เข้ากับ LLM ตัวไหน — OpenAI, Claude, DeepSeek หรืออื่นๆ |
